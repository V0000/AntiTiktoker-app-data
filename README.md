# Данные для репозитория AntiTiktoker-app-data

Содержимое этой папки нужно скопировать **в корень** GitHub-репозитория
[V0000/AntiTiktoker-app-data](https://github.com/V0000/AntiTiktoker-app-data)
(GitHub Pages: `https://v0000.github.io/AntiTiktoker-app-data/`).

```
index.json          ← манифест: список всех пакетов
grade1.json … grade9.json   ← пакеты заданий (математика 1–9 класс)
```

## Как это работает

- Приложение раз в сутки (и по кнопке «Обновить сейчас» в настройках) скачивает `index.json`.
- Для каждого пакета из манифеста файл качается **только если изменился `revision`**.
- Файлы, пропавшие из манифеста, удаляются из кэша приложения.
- Встроенный в приложение контент используется, пока удалённая загрузка ни разу не
  удалась; скачанные пакеты перекрывают встроенные с тем же ключом
  `subject_grade_term`.

## Как изменить существующий класс

1. Отредактируйте `gradeN.json` (формата файла см. ниже).
2. В `index.json` увеличьте `revision` этого пакета на 1.
3. Закоммитьте и запушьте. Приложение скачает обновление при ближайшем обновлении контента.

## Как добавить новый пакет (например, русский язык)

1. Создайте файл `russian_grade5.json` с полями `"subject": "russian", "grade": 5, "term": "0"`.
2. Добавьте в `packages` в `index.json`:
   `{ "subject": "russian", "grade": 5, "term": "0", "url": "russian_grade5.json", "revision": 1 }`.
3. Пакет появится в дереве «Предмет → Класс → Период → Тема» автоматически.

## Формат пакета

```json
{
  "contentVersion": 2,
  "subject": "mathematics",
  "grade": 5,
  "term": "0",
  "topics": [
    {
      "id": "percents",
      "title": "Проценты",
      "tasks": [
        {
          "id": "pc_of_001",
          "title": "Процент от числа",
          "question": "Найди {P}% от числа {N}.",
          "variables": {
            "P": { "type": "integer", "min": 5, "max": 25, "step": 5 },
            "N": { "type": "integer", "min": 100, "max": 900, "step": 100 }
          },
          "constraints": [],
          "answer": "N * P / 100",
          "answerType": "integer",
          "explanation": "{N} × {P} ÷ 100 = {N * P / 100}.",
          "difficulty": 2
        }
      ]
    }
  ]
}
```

### Поля

| Поле | Описание |
|---|---|
| `contentVersion` | Версия схемы. Приложение поддерживает `<= 2`; пакет с большей версией пропускается |
| `term` | `"0"` = «Весь год» (дерево: «N класс → Весь год»). Можно `"1"`…`"4"` = четверти |
| `question` | Текст с подстановками `{A}`, `{B}` и целыми выражениями `{A + B}`, `{max(P, Q)}` |
| `variables` | Диапазоны значений: `type` = `integer`/`decimal`, `min`, `max`, `step` |
| `constraints` | Условия валидности, например `"A % B == 0"`, `"A + B <= 20"`, `"P < Q"` |
| `answer` | Выражение ответа (то же мини-язык, что и в constraints) |
| `answerType` | `integer` — ответ обязан быть целым; `decimal` — принимается с точностью 0.01 |
| `difficulty` | 1–3: влияет на адаптивный отбор (ребёнок стабильно справляется — задания сложнее, затрудняется — проще) |
| `enabled` | `false` — шаблон исключается из выдачи |

### Мини-язык выражений (question, constraints, answer, explanation)

- Приоритет операций стандартный: `*`, `/`, `%` старше `+`, `-`; есть скобки `( )` и унарный минус.
- Переменные — имена из ЗАГЛАВНЫХ букв: `A`, `B`, `N`… (вопрос текстовый регистр сохраняет).
- Функции: `min(a,b)`, `max(a,b)`, `abs(a)`, `sqrt(a)`, `pow(a,b)`, `gcd(a,b)`, `lcm(a,b)`.
- В `constraints`: `==`, `!=`, `<`, `<=`, `>`, `>=` между двумя выражениями.
- Внутри `{...}` в тексте можно любое выражение: `{(A + B) * 2}`, `{sqrt(A * A)}`.

### Важно

- Ответ при `answerType: "integer"` обязан получаться целым числом — иначе шаблон
  будет отброшен генератором. Для гарантии целочисленности используйте `step`
  переменных и ограничения (`"A % B == 0"`).
- Шаблон с невыполнимыми constraints не выдаётся (генератор делает 200 попыток).
- В поле ввода ответа ребёнок может вводить отрицательные числа (кнопка «−»).
